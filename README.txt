BODY TOWN GYM — GITHUB ROOT FILES

All files are in this one folder. Upload every file directly to the root of your GitHub repository.

Files:
- index.html
- style.css
- script.js
- gym-photo-01.jpg
- gym-photo-02.jpg
- gym-photo-03.jpg
- gym-photo-04.jpg

Do not create css/, js/, or assets/ folders.
Keep all files together at the repository root.

GitHub Pages:
1. Upload all files to the repository root.
2. Open Settings > Pages.
3. Select Deploy from a branch, choose main and /(root), then Save.
4. Wait for GitHub Pages deployment.

The contact form uses the Web3Forms access key already configured in index.html.
